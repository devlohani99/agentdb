# Relay

Multi-tenant agent memory on FalkorDB for Graph Hacks (Track 02).

## Phase 1

Monorepo skeleton, Docker infra, and `@relay/shared` utilities.

```bash
npm install
npm run build
npm test
make up
```

- App UI: http://localhost:8080
- Grafana: http://localhost:3001 (admin / admin)
- Prometheus: http://localhost:9090
